How the Pipeline Works

Four stages from raw job data to personalised skill gap report

1
Data Collection

Job listings are scraped and stored in a SQLite database with descriptions and metadata.

2
AI Tagging

Gemini AI reads each job description in batches and extracts the required tech stack automatically.

3
Resume Parsing

Your resume (PDF or text) is parsed by AI to extract your current technical skills accurately.

4
Gap Analysis

A deterministic set subtraction finds exactly what skills jobs require that your resume doesn't have.

Features

Everything you need to understand your position in the job market

🔒
Jailbreak Protection

Resume inputs are scanned for prompt injection attempts before reaching the AI model.

📄
PDF Upload

Upload your resume as a PDF — text is extracted client-side and sent securely to the backend.

📊
Demand Statistics

See which missing skills are most in-demand, with charts showing real distribution from job data.

🔁
Deterministic Results

Gap analysis uses exact set subtraction — not AI judgement — so results are consistent every run.

⚡
Batch Processing

Jobs are tagged in batches with automatic retry and rate-limit handling for reliability.

🐳
Fully Containerised

Frontend, backend, and LLM service each run in isolated Docker containers with a shared network.

How to Build & Run

Get the full stack running in minutes

1
Clone the repository 
git clone <your-repo-url>
cd week_3
2
Create secrets file 
mkdir secrets
echo "your_google_api_key" > secrets/google_api_key.txt
3
Build and start all services 
docker compose up --build
4
Pull the LLM model (first run only) 
docker exec -it ollama ollama pull llama3.1
5
Tag the job database 
docker exec -it week_3-backend-1 \
  uv run python src/week_2/tag_data.py
6
Access the services 
Chatbot:    http://localhost:8000
Stats:      http://localhost:8000/stats
Backend:    http://localhost:8001
Landing:    http://localhost:8080
